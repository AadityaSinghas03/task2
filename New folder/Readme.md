# Laundry Wallah / Laundry Mart

## About the Project
Laundry Wallah is a simple and user-friendly laundry service website developed using HTML. It provides information about laundry services, pricing, and an online booking form.

The main purpose of this project is to make laundry services easy and convenient for customers.

## Features
- Introduction to Laundry Wallah.
- List of available laundry services.
- Price list of laundry services.
- Customer booking form.
- Name, Email, and Phone Number fields.
- Contact information in the footer.

## Services Offered
1. Washing Service
2. Dry Cleaning
3. Ironing Service
4. Drying & Folding
5. Pickup & Delivery

## Technologies Used
- HTML5

## How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Open the `index.html` file in any web browser.
4. The Laundry Wallah website will appear.
